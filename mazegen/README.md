# Mazegen

`mazegen` is a Python package for generating and solving mazes.

The package provides a `MazeGenerator` class that can be imported and used
from other Python projects. It supports multiple maze generation algorithms,
custom maze dimensions, entry and exit positions, reproducible generation
using a seed, and access to the generated maze and its solution.

## Installation

Install the package using the generated wheel:

```bash
pip install mazegen-1.0.0-py3-none-any.whl
```

Once installed, the package can be imported with:

```python
from mazegen import MazeGenerator
```

### Basic Usage:
A maze can be generated by creating a MazeGenerator instance:

```python
from mazegen import MazeGenerator

maze = MazeGenerator(
    width=10,
    height=10,
    entry=(0, 0),
    exit=(9, 9),
    output_file="maze.txt",
    use_seed=False,
)
```

Creating the instance generates the maze automatically.

The generated maze is stored in:

```python
maze.grid
```

The entry and exit cells are available through:

```python
maze.entry
maze.exit
```

The solution path is available through:

```python
maze.solution
```

For example:

```python
for cell in maze.solution:
    print(cell.position)
```

This prints the coordinates of the cells that form the solution path from
the entry to the exit.

### Custom parameters

MazeGenerator accepts several parameters that can be used to customize
the generated maze.

```python
maze = MazeGenerator(
    width=20,
    height=10,
    entry=(0, 0),
    exit=(19, 9),
    output_file="my_maze.txt",
    use_seed=True,
    seed=42,
    perfect=True,
    algorithm="ab",
)
```

### Parameters
| Parameter     | Type              | Description                                                 |
| ------------- | ----------------- | ----------------------------------------------------------- |
| `width`       | `int`             | Width of the maze in cells.                                 |
| `height`      | `int`             | Height of the maze in cells.                                |
| `entry`       | `tuple[int, int]` | `(x, y)` coordinates of the entry cell.                     |
| `exit`        | `tuple[int, int]` | `(x, y)` coordinates of the exit cell.                      |
| `output_file` | `str`             | File where the generated maze is exported.                  |
| `use_seed`    | `bool`            | Enables or disables seeded generation.                      |
| `seed`        | `int \| None`     | Seed used to reproduce the same maze.                       |
| `perfect`     | `bool`            | Determines whether the maze should be perfect or imperfect. |
| `algorithm`   | `str`             | Algorithm used to generate the maze.                        |


### Generation algorithms

The package currently supports two maze generation algorithms:

ab - Aldous-Broder
dfs - Depth First Search

The algorithm can be selected using the algorithm parameter:

```python
maze = MazeGenerator(
    width=10,
    height=10,
    entry=(0, 0),
    exit=(9, 9),
    output_file="maze.txt",
    use_seed=True,
    seed=42,
    algorithm="dfs",
)
```
The default algorithm is ab (Aldous-Broder).

### Accessing the generated maze

The generated maze is stored in the grid attribute:

```python
grid = maze.grid
```

The grid is a two-dimensional list of Cell objects:

```python
for row in maze.grid:
    for cell in row:
        print(cell.position, cell.walls)
```

Each Cell contains information about its position and walls.

A Cell can be accessed using its coordinates:

```python
cell = maze.grid[y][x]
```

The walls value is a bitmask representing the walls of the cell.

The four wall values are represented by the DIRECTION enum:

```python
from mazegen import DIRECTION

print(DIRECTION.NORTH)
print(DIRECTION.EAST)
print(DIRECTION.SOUTH)
print(DIRECTION.WEST)
```

### Accessing the entry and exit

The entry and exit cells can be accessed directly:

```python
entry = maze.entry
exit = maze.exit

print(entry.position)
print(exit.position)
```

### Accessing the solution

After the maze has been generated, the shortest solution found using
Breadth-First Search is available through the solution attribute:

```python
solution = maze.solution
```

The solution is a list of Cell objects:

```python
for cell in maze.solution:
    print(cell.position)
```

For example, the output could look like:

```python
(0, 0)
(1, 0)
(1, 1)
(2, 1)
(2, 2)
(3, 2)
```
The first cell is the entry and the last cell is the exit.

### Complete example:
The following example creates a maze, prints its dimensions, displays
the entry and exit positions, and prints the solution path:

```python
from mazegen import MazeGenerator

maze = MazeGenerator(
    width=10,
    height=10,
    entry=(0, 0),
    exit=(9, 9),
    output_file="maze.txt",
    use_seed=True,
    seed=42,
    perfect=True,
    algorithm="ab",
)

print(f"Maze size: {maze.width} x {maze.height}")
print(f"Entry: {maze.entry.position}")
print(f"Exit: {maze.exit.position}")

print("Solution:")
for cell in maze.solution:
    print(cell.position)
```

### Package structure:

The main components of the package are:

```python
mazegen/
├── __init__.py
├── generator.py
├── cell.py
├── enums.py
├── aldous_broder.py
├── depth_first_search.py
├── breadth_first_search.py
├── alg_utils.py
├── config.py
├── errors.py
└── export.py
```

The main public class is:

```python
from mazegen import MazeGenerator
```
MazeGenerator is responsible for creating the maze, selecting the
generation algorithm, generating the solution, and exporting the result.
